1. Arquitectura y Requisitos del Sistema

Diseño desacoplado, motor autónomo y conectividad local multiplataforma.

Next.js Standalone

Servidor web autónomo precompilado. Opera sin depender de herramientas de compilación en el computador del cliente.

SQLite con Motor WAL

Base de datos relacional ultraligera protegida con Write-Ahead Logging (WAL) contra pérdidas ante cortes imprevistos de energía.

Bonjour mDNS Local

Permite a celulares, tablets y computadores conectarse a la red Wi-Fi escribiendo directamente http://llanomio.local:3000.

Despliegue Asistido y Automatizado

2. Instalación con Asistente GUI (.EXE)

Pasos exactos para implementar el sistema en un equipo comercial nuevo.

1
Ejecución del Asistente Maestro

Inicia Instalador_Maestro_Unico_POS.exe. El programa solicitará elevación de Administrador de Windows (UAC) para configurar las reglas de red y los servicios del sistema.

2
Selección de Modo de Instalación
Modo Rápido 1-Clic (Recomendado) Establece puerto 3000, dominio llanomio.local, autoarranque en Windows y accesos directos en el escritorio.
Modo Personalizado Permite cambiar el puerto HTTP, el nombre de red, elegir si restablecer la base de datos o conservar datos previos.
3
Monitoreo de Progreso en Vivo

El asistente muestra una barra de progreso porcentual (0% a 100%) y una consola de registro en tiempo real que ejecuta las siguientes acciones:

  • Liberación quirúrgica de puertos ocupados.
  • Generación del archivo de configuración .env de producción.
  • Creación de la bóveda central de respaldos en C:\POS_BACKUPS\.
  • Aseguramiento de credenciales maestras del administrador en SQLite.
  • Apertura de reglas en Windows Defender Firewall (TCP 3000 y UDP 5353 Bonjour).
  • Creación de la botonera oficial en el Escritorio.
4
Finalización y Apertura Automática

Al llegar al 100%, el instalador habilita el botón "Abrir POS Ahora", levantando el servidor en segundo plano y mostrando la interfaz en pantalla completa lista para operar.

3. Suite de Ejecutables Nativos (.EXE)

Funciones técnicas de cada ejecutable instalado en el Escritorio del usuario.

Iniciar_Servidor_POS.exe

Control Diario: Realiza una petición HTTP de sondeo al puerto local. Si el servidor está apagado, lo levanta mediante PM2 en segundo plano. Luego, abre Microsoft Edge o Google Chrome en modo aplicación nativa (--app=http://127.0.0.1:3000/login) en pantalla maximizada respetando la barra de tareas.

Detener_Servidor_POS.exe

Protección Financiera Activa: Antes de detener los procesos, consulta el estado de la caja (/api/caja/estado). Si existe un turno abierto, bloquea el apagado y avisa al usuario para que realice el arqueo y cierre. Si la caja está cerrada, genera un respaldo preventivo y libera los puertos limpiamente.

Reiniciar_Servidor_POS.exe

Optimización en Caliente: Ejecuta un vaciado pasivo de registros WAL de SQLite (PRAGMA wal_checkpoint), recicla los hilos de PM2 en menos de 4 segundos y refresca la conexión del navegador sin alterar la sesión de trabajo.

Recuperar_Servidor_POS.exe

Rescate Quirúrgico y Diagnóstico: Diseñado para recuperar el sistema ante cortes imprevistos de luz o fallos de red. Diagnostica bloqueos de puertos, repara permisos, asegura la existencia de credenciales y levanta el servicio al estado previo.

4. Seguridad y Protocolo de 3 Factores

Roles de usuario (RBAC) y restauración segura contra ataques de fuerza bruta.

Credenciales Iniciales de Fábrica

Usuario admin
Contraseña admin123
Documento 3F 0000000000
PIN de Seguridad 000000

Protocolo de 3 Factores Locales (Anti-Hackeo)

Para restaurar una contraseña olvidada sin conexión a internet y sin vulnerar la base de datos, el sistema valida directamente contra hashes bcrypt en SQLite:

Factor 1: Identidad Cédula o NIT registrado en la cuenta.
Factor 2: PIN Confidencial PIN numérico privado de 6 dígitos.
Factor 3: Desafío Secreto Respuesta a la pregunta de seguridad elegida.
Protección contra fuerza bruta: Si se introducen datos incorrectos 3 veces consecutivas, la cuenta se bloquea en base de datos durante 15 minutos de forma persistente.
Mostrador Comercial Especializado

5. Operación de las 3 Cajas Homologadas

Módulos especializados para venta, alquiler y reserva sin fricción operativa.

Terminal de Ventas POS y Sastrería (/caja/pos)

Terminal Verde

Permite facturar productos terminados, prendas comerciales o servicios de sastrería y arreglos. Admite lectura con escáner de códigos de barras USB/Bluetooth, búsqueda instantánea por nombre o documento, y pagos divididos (ej. parte en Efectivo y parte por Transferencia).

Terminal de Alquileres y Depósitos (/caja/alquileres)

Terminal Naranja

Controla el préstamo de prendas con contrato de custodia. Exige un Depósito en Garantía en Efectivo que permanece registrado en la gaveta física del cajero hasta la devolución de las prendas en buen estado. Calcula automáticamente penalizaciones por mora diaria si la fecha pactada expira.

Terminal de Apartados y Reservas (/caja/apartados)

Terminal Morada

Permite a los clientes apartar artículos para eventos futuros realizando abonos escalonados. Bloquea las prendas en el inventario para evitar cruces con ventas o alquileres inmediatos, y emite comprobantes de saldo pendiente exigible.

Auditoría Financiera en Tiempo Real

7. Control de Turnos y Arqueo Ciego

Cierre estricto sin descuadres y control automático del cajón monedero.

Fórmula Matemática de Arqueo:
Efectivo Esperado = Base Inicial + Ventas Efectivo + Depósitos Custodia - Egresos/Gastos
Arqueo Ciego (Doble Validación)

Al momento del cierre, el software no le revela el total recaudado al cajero. El dependiente debe contar y digitar físicamente los billetes y monedas. Una vez confirmado, el sistema emite el acta de cierre señalando si hubo cuadre exacto, sobrante o faltante.

Apertura Automática del Cajón

El cajón monedero RJ11 se dispara mediante pulsos directos de la impresora térmica o presionando la tecla rápida F2 en cualquier momento que se requiera dar cambio.

Bóveda Central de Seguridad (C:\POS_BACKUPS)

El sistema mantiene aisladas las copias de seguridad en la raíz del disco C:\POS_BACKUPS\ para que nunca se pierdan si se desinstala o actualiza el aplicativo.

Snapshots Diarios /historial/
Libro de Ventas /historial_facturas/

Protocolo de Restauración en Computador Nuevo

  1. Instala el sistema con el asistente en el equipo nuevo.
  2. Detén el servidor con Detener_Servidor_POS.exe.
  3. Copia tu archivo llanomio.db de respaldo dentro de la carpeta C:\POS_Llanomio\database\.
  4. Inicia el servidor con Iniciar_Servidor_POS.exe. La totalidad de clientes, facturas y deudas quedarán recuperados al instante.
