2. Instalación y Despliegue en Equipo Nuevo

Pasos para dejar el sistema listo para operar en cualquier computador nuevo.

1 Paso Inicial

Ejecutar el Instalador

Haz doble clic sobre Aurora_Host_POS_Setup.exe y concede permisos de Administrador (UAC).

2 Automático

Configuración Desatendida

El instalador descomprime el motor, vincula la base de datos de fábrica y configura las reglas de Firewall de Windows en el puerto 3000.

3 ¡Listo!

Botonera en el Escritorio

Se crearán en el Escritorio los accesos directos para encender, detener o relanzar el sistema con sus iconos oficiales.

Instalación Manual o Portable Alternativa:

Si prefieres instalar desde la carpeta de archivos, haz clic derecho sobre INSTALADOR_MAESTRO_UNICO_POS.bat y selecciona "Ejecutar como Administrador".

3. Operación Diaria del Cajero y Usuario

Cómo iniciar y apagar el sistema sin requerir conocimientos técnicos.

Iniciar_Servidor_POS.exe

Botón Maestro de Encendido y Apertura
  • Si el servidor está apagado: Lo levanta silenciosamente y abre la terminal en pantalla completa.
  • Si el servidor ya está activo: No reinicia procesos; abre inmediatamente la ventana de mostrador.
  • Barra de Windows respetada: Abre la ventana maximizada para permitir el uso de la barra de tareas de Windows.
Ideal para carpeta de Inicio de Windows (shell:startup)

Detener_Servidor_POS.exe

Botón de Apagado Limpio y Seguro
  • Respaldo en Caliente: Realiza una copia de seguridad preventiva de SQLite antes de apagar.
  • Cierre de Procesos: Detiene de forma limpia los procesos de Node y PM2.
  • Liberación de Puertos: Deja libre el puerto 3000 sin colgar el computador.
Úsalo al terminar la jornada laboral

8. Control de Turnos, Arqueos y Cajón Monedero

Auditoría en tiempo real para evitar descuadres de efectivo.

Apertura de Turno

Al iniciar la jornada, el sistema solicita ingresar la Base Inicial de Efectivo disponible en gaveta. Esto fija el punto de partida contable.

Fórmula: Esperado en Gaveta = Base Inicial + Ventas Efectivo + Depósitos Alquiler - Retiros/Gastos

Cierre de Turno y Arqueo Ciego

El cajero ingresa el conteo físico real de billetes y monedas. El sistema calcula automáticamente si hay sobrante, faltante o cuadre exacto, registrando la auditoría del turno.

[F2] Abre el cajón monedero [F4] Cobro rápido

9. Carga Masiva y Gestión de Catálogos

Cómo ingresar clientes y prendas rápidamente mediante Excel o formularios.

Directorio de Clientes

Puedes registrar clientes individualmente desde el mostrador (Paso 1) o de forma masiva desde Menú > Clientes. Se permite exportar a Excel y cargar planillas de contactos existentes.

Inventario de Prendas y Productos

En Menú > Inventario puedes definir si una prenda es para Venta o para Alquiler, asignando código de barras, talla, color, categoría, precio base y precio de depósito.

10. Copias de Seguridad (Backups) y Restauración

Protección integral de los datos contables y facturas del negocio.

Aurora-POS almacena toda la información en la base de datos ultraligera database/llanomio.db bajo modo SQLite WAL resistente a apagones bruscos.

1. Respaldos Automáticos

Cada vez que el cajero cierra sesión o se apaga el servidor, se guarda una copia en C:\POS_BACKUPS\.

2. Respaldo Manual

Desde Ajustes > Copia de Seguridad puedes hacer clic en "Generar Respaldo Ahora" y descargar el archivo .db a una memoria USB.

3. Restauración Segura

Si cambias de computador, basta con restaurar tu archivo de backup desde el panel para recuperar clientes, ventas y deudas al instante.
