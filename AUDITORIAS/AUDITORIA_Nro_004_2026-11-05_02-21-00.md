### Dimension 3 -- Automatizacion y Monitoreo Zabbix Agent 2
1. **Descarga e Instalacion Desatendida:**
   - Deteccion automatica del paquete MSI en `bin/` o descarga segura via TLS 1.2 desde el CDN oficial de Zabbix (`zabbix_agent2-7.0.0-windows-amd64-openssl.msi`).
   - Instalacion silenciosa mediante `msiexec.exe /i ... /qn /norestart`.
2. **Inyeccion de UserParameters Oficiales (`pos_llanomio.conf`):**
   - `UserParameter=pos.llanomio.http.status[*],powershell -NoProfile -WindowStyle Hidden -Command "try { $r = Invoke-WebRequest -Uri 'http://127.0.0.1:$1/login' -UseBasicParsing -TimeoutSec 3; $r.StatusCode } catch { 0 }"`
   - `UserParameter=pos.llanomio.db.size,powershell -NoProfile -WindowStyle Hidden -Command "if (Test-Path '%PROJECT_ROOT%\database\llanomio.db') { (Get-Item '%PROJECT_ROOT%\database\llanomio.db').Length } else { 0 }"`
   - `UserParameter=pos.llanomio.node.running,powershell -NoProfile -WindowStyle Hidden -Command "(Get-Process -Name node -ErrorAction SilentlyContinue | Measure-Object).Count"`
   - Alias retrocompatibles incluidos: `pos.status`, `pos.db.size`, `pos.node.processes`.
3. **Firewall y Servicio:**
   - Apertura de puertos TCP 10050 (inbound) y TCP 10051 (outbound) en Windows Firewall.
   - Configuracion del servicio en modo automatico (`sc config "Zabbix Agent 2" start= auto`).
