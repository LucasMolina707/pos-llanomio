================================================================================
          SISTEMA POS LOCAL LLANOMIO - MANUAL OFICIAL DE INSTALACION
                      GUIA PASO A PASO PARA EQUIPOS NUEVOS
================================================================================

Este manual explica de forma detallada y sencilla como instalar y poner en marcha
el sistema POS LLANOMIO en cualquier computador con sistema operativo Windows
(Windows 10 o Windows 11 de 64 bits).

El manual cubre dos metodos de instalacion:
  METODO A: Descarga directa desde el repositorio de GitHub (Recomendado con internet).
  METODO B: Instalacion utilizando una memoria USB o disco externo con los archivos.


================================================================================
1. REQUISITOS PREVIOS DEL COMPUTADOR (QUE DEBE INSTALAR ANTES)
================================================================================

Antes de instalar el sistema POS, asegurese de tener instalados los siguientes dos
programas gratuitos en el computador principal:

1.1. NODE.JS (MOTOR DE EJECUCION JAVASCRIPT) - OBLIGATORIO
--------------------------------------------------------------------------------
- Que es: Es el motor que permite ejecutar la aplicacion web y la base de datos local.
- Version recomendada: Node.js LTS (Version 20 o Version 22).
- Enlace de descarga oficial:
  https://nodejs.org/
- Instrucciones de instalacion:
  1. Ingrese a https://nodejs.org/ y descargue la version que dice "LTS" (Recomendada).
  2. Ejecute el instalador descargado (.msi).
  3. Presione "Next" (Siguiente) en todas las pantallas aceptando los terminos.
  4. Al finalizar la instalacion, presione "Finish".
  5. Para comprobar que quedo bien instalado:
     - Abra el menu Inicio de Windows, escriba "cmd" y presione Enter.
     - Escriba el siguiente comando y presione Enter:
       node -v
     - Debe responderle con la version instalada (ejemplo: v20.18.0 o superior).

1.2. GIT PARA WINDOWS (CONTROL DE VERSIONES) - OBLIGATORIO PARA METODO GITHUB
--------------------------------------------------------------------------------
- Que es: Permite clonar y mantener sincronizado el codigo del sistema.
- Enlace de descarga oficial:
  https://git-scm.com/download/win
- Instrucciones de instalacion:
  1. Descargue el instalador para Windows de 64 bits.
  2. Ejecutelo y mantenga las opciones por defecto recomendadas presionando "Next".
  3. Para comprobar que quedo bien instalado, en la consola CMD escriba:
     git --version


================================================================================
2. UBICACION RECOMENDADA EN EL DISCO DURO (DONDE GUARDAR EL SISTEMA)
================================================================================

Se recomienda ubicar el sistema en una ruta corta, sin espacios ni caracteres
especiales en el disco local principal (C:).

Rutas recomendadas:
  C:\Proyectos\pos-llanomio
  o directamente:
  C:\pos-llanomio


================================================================================
3. OBTENCION DE LOS ARCHIVOS DEL PROYECTO
================================================================================

Elija uno de los siguientes dos metodos segun su situacion:

--------------------------------------------------------------------------------
METODO A: CLONAR DIRECTAMENTE DESDE GITHUB (CON CONEXION A INTERNET)
--------------------------------------------------------------------------------
1. Abra la consola de comandos de Windows (CMD o PowerShell).
2. Ubiquese en la carpeta donde desea colocar el proyecto. Por ejemplo, escriba:
   cd C:\
   mkdir Proyectos
   cd C:\Proyectos
3. Clone el repositorio oficial ejecutando el siguiente comando exacto:
   git clone https://github.com/LucasMolina707/pos-llanomio.git
4. Ingrese a la carpeta recien clonada:
   cd pos-llanomio
5. Listo. Ya tiene todos los archivos del sistema descargados en:
   C:\Proyectos\pos-llanomio

--------------------------------------------------------------------------------
METODO B: COPIAR DESDE UNA MEMORIA USB O DISCO EXTERNO (SIN GITHUB)
--------------------------------------------------------------------------------
1. Conecte su memoria USB o disco extraible al computador.
2. Abra el Explorador de Archivos de Windows y localice la carpeta "pos-llanomio"
   dentro de su memoria USB.
3. Copie la carpeta completa "pos-llanomio" (Clic derecho -> Copiar).
4. Vaya a su disco local (C:), cree una carpeta llamada "Proyectos" (o en la raiz C:)
   y pegue la carpeta alli.
   La ruta debe quedar asi:
   C:\Proyectos\pos-llanomio
   
   IMPORTANTE:
   NO ejecute el sistema directamente dentro de la memoria USB. Debe estar copiado
   en el disco solido (SSD o HDD) del computador para garantizar maxima velocidad
   en la base de datos y evitar corrupcion de archivos si la memoria es desconectada.


================================================================================
4. PROCESO DE INSTALACION AUTOMATICA (PASO A PASO)
================================================================================

Una vez que la carpeta "pos-llanomio" se encuentre en su disco local, siga estos
pasos:

PASO 1: ABRIR LA CARPETA DEL INSTALADOR
--------------------------------------------------------------------------------
1. Abra el Explorador de Archivos de Windows.
2. Navegue a la siguiente carpeta dentro del proyecto:
   C:\Proyectos\pos-llanomio\instalador_tienda

3. Encontrara los siguientes archivos ejecutables de automatizacion (.bat):
   - 1_INSTALAR_POS_GITHUB.bat
   - 2_iniciar_sistema_pm2.bat
   - 5_ABRIR_FIREWALL_LAN.bat
   - CONFIGURAR_PUERTOS_RED.bat

PASO 2: EJECUTAR EL INSTALADOR OFICIAL
--------------------------------------------------------------------------------
1. Haga doble clic en el archivo:
   1_INSTALAR_POS_GITHUB.bat
   (O haga clic derecho sobre el y elija "Ejecutar como administrador").

2. Se abrira una ventana de consola azul/negra que realizara 7 pasos automaticos:
   [1/7] Verificacion de dependencias (Node.js y Git).
   [2/7] Creacion de carpetas de respaldos locales (C:\POS_LLANOMIO_BACKUPS).
   [3/7] Creacion del archivo de variables de entorno (.env).
   [4/7] Analisis y verificacion dinamica de puertos de red.
   [5/7] Instalacion de dependencias (librerias de Node.js mediante npm install).
   [6/7] Generacion de base de datos SQLite limpia de fabrica (database\llanomio.db).
   [7/7] Compilacion optimizada de la aplicacion Next.js para produccion.

PASO 3: CONFIGURACION INTERACTIVA DE PUERTOS DE RED (DURANTE EL PASO 4/7)
--------------------------------------------------------------------------------
Durante la instalacion, el script analizara si los puertos de red estandar estan libres:
  - Puerto 3000: Motor web interno de Next.js.
  - Puerto 80: Acceso web local y proxy para celulares (http://llanomio.local).

CASO 1: Ambos puertos estan libres.
  El instalador continuara automaticamente sin pedir nada y guardara la configuracion.

CASO 2: Algun puerto esta ocupado por otro programa (ej. IIS, Skype o Apache).
  El instalador pausara la pantalla, le informara que programa ocupa el puerto y
  le preguntara:
  
  Pregunta 1:
  "Ingrese el puerto web deseado para Next.js [Por defecto 3000]:"
  -> Si el 3000 esta libre o desea usar el sugerido (ej. 3001), presione Enter
     o escriba el numero de puerto libre que desee.

  Pregunta 2:
  "Ingrese el puerto HTTP local [Por defecto 80]:"
  -> Si el 80 esta ocupado por Windows, puede ingresar un puerto alternativo
     como 8080 o presionar Enter para aceptar el sugerido libre.

El instalador guardara automaticamente estos puertos en el archivo .env sin que usted
tenga que editar codigo manualmente.

PASO 4: ESPERAR LA FINALIZACION DE LA COMPILACION
--------------------------------------------------------------------------------
El paso 7/7 realizara la compilacion de produccion. Este proceso tarda entre 30 y 60
segundos. Al terminar, la consola mostrara el mensaje:
  "INSTALACION COMPLETADA CON EXITO"
Presione cualquier tecla para cerrar la ventana.


================================================================================
5. PUESTA EN MARCHA DEL SISTEMA EN SEGUNDO PLANO (SERVICIO PERSISTENTE)
================================================================================

Para que el sistema se mantenga funcionando siempre en segundo plano (sin tener
ventanas negras abiertas) y arranque automaticamente al encender el computador:

1. Ingrese a la carpeta:
   C:\Proyectos\pos-llanomio\instalador_tienda

2. Haga doble clic en el archivo:
   2_iniciar_sistema_pm2.bat

3. Que hace este script:
   - Inicia la aplicacion web POS en segundo plano con PM2.
   - Inicia el servicio mDNS (Bonjour) para anunciar "llanomio.local" en el Wi-Fi.
   - Crea un acceso directo en la carpeta "Inicio" de Windows
     (Shell:startup / Iniciar_LLANOMIO_Auto.bat) para que el sistema se inicie
     solo cada vez que prenda el computador de la tienda.


================================================================================
6. CONFIGURACION DEL FIREWALL DE WINDOWS (PARA CELULARES Y TABLETS)
================================================================================

Para permitir que los celulares y tablets de los empleados puedan conectarse al POS
mediante la red Wi-Fi de la tienda sin que el Firewall de Windows los bloquee:

1. Ingrese a la carpeta:
   C:\Proyectos\pos-llanomio\instalador_tienda

2. Haga CLIC DERECHO sobre el archivo:
   5_ABRIR_FIREWALL_LAN.bat
   y seleccione: "Ejecutar como administrador".

3. El script abrira los puertos TCP correspondientes (80 y 3000 o los elegidos)
   y el puerto UDP 5353 para la deteccion automatica por mDNS.


================================================================================
7. COMO ACCEDER AL SISTEMA (DIRECCIONES DE ACCESO)
================================================================================

7.1. DESDE EL COMPUTADOR PRINCIPAL DE LA TIENDA
--------------------------------------------------------------------------------
Abra Google Chrome, Microsoft Edge o su navegador favorito e ingrese a cualquiera
de estas dos direcciones:
  http://localhost
  o
  http://llanomio.local

(Nota: Si configuro un puerto HTTP diferente, por ejemplo 8080, ingrese a:
 http://localhost:8080 o http://llanomio.local:8080).

7.2. DESDE CELULARES Y TABLETS CONECTADOS AL WI-FI DE LA TIENDA
--------------------------------------------------------------------------------
Conecte el celular a la misma red Wi-Fi de la tienda y abra el navegador (Chrome o Safari).
Ingrese a:
  http://llanomio.local

Tambien puede escanear directamente con la camara del celular el Codigo QR que
aparece en pantalla en la barra superior o en el menu de "Configuracion de Red Local".


================================================================================
8. CREDENCIALES MAESTRAS DE ACCESO INICIAL
================================================================================

Al ingresar por primera vez a la pantalla de Login, use las siguientes credenciales:

  - Usuario:              admin
  - Clave inicial:        admin123
  - Rol asignado:         ADMIN (Administrador General de la Tienda)

FACTORES DE RECUPERACION MAESTRA (EN CASO DE OLVIDO DE CLAVE):
En la pantalla de login puede usar el boton "¿Olvidaste tu contraseña?" e ingresar:
  - Documento / Cedula:   0000000000
  - PIN de Seguridad:     000000
  - Pregunta:             "Nombre de la tienda"
  - Respuesta:            llanomio
  - Llave Maestra Servidor: LLANOMIO-ADMIN-2026

PRIMERAS ACCIONES RECOMENDADAS DESPUES DE ENTRAR:
1. Vaya al menu lateral -> "Configuracion":
   - Cambie el Nombre de la Tienda por el de su negocio.
   - Ingrese su NIT, Telefono, Direccion y suba el Logo de su empresa.
2. Vaya al menu lateral -> "Usuarios":
   - Cambie la clave inicial del administrador "admin" por una clave propia y segura.
   - Cree los usuarios para sus cajeros o vendedores con rol "CAJERO".


================================================================================
9. RECONFIGURACION DE PUERTOS DE RED EN EL FUTURO
================================================================================

Si en el futuro instala otro programa en el computador que cause conflicto de puertos:
1. Vaya a:
   C:\Proyectos\pos-llanomio\instalador_tienda
2. Ejecute:
   CONFIGURAR_PUERTOS_RED.bat
3. Ingrese los nuevos puertos libres que desee y presione Enter.
4. El script actualizara el archivo .env y reiniciara automaticamente los servicios
   de PM2 sin interrumpir su base de datos.


================================================================================
10. COPIAS DE SEGURIDAD (RESPALDOS) Y MANTENIMIENTO
================================================================================

10.1. REALIZAR UN RESPALDO MANUAL
--------------------------------------------------------------------------------
- Opcion 1: Desde el navegador, ingrese a "/admin/configuracion" y presione el
  boton "Generar Copia de Seguridad Ahora".
- Opcion 2: Ejecute el archivo:
  C:\Proyectos\pos-llanomio\instalador_tienda\3_RESPALDO_MANUAL.bat

Donde se guardan los respaldos:
  C:\POS_LLANOMIO_BACKUPS
  y en:
  C:\Proyectos\pos-llanomio\database\backups_locales

10.2. RESTAURAR UNA COPIA DE SEGURIDAD ANTERIOR
--------------------------------------------------------------------------------
Si necesita volver a un punto anterior:
1. Ejecute el archivo:
   C:\Proyectos\pos-llanomio\instalador_tienda\4_RESTAURAR_RESPALDO.bat
2. Elija la fecha y archivo de respaldo que desea restaurar.


================================================================================
11. RESUMEN RAPIDO DE COMANDOS MANUALES (SOLO PARA DESARROLLADORES O CONSOLA)
================================================================================

Si en lugar de usar los archivos .bat prefiere usar la consola de comandos (CMD):

  cd C:\Proyectos\pos-llanomio
  npm install                     (Instala librerias)
  npx prisma generate             (Genera cliente de base de datos)
  npx prisma db push              (Sincroniza tablas en llanomio.db)
  npm run db:seed                 (Aplica sembrado limpio inicial)
  npm run build                   (Compila la aplicacion)
  npm run start                   (Arranca en modo produccion manual)
  node scripts/verificar-puertos.js (Verifica puertos de red)
  npx pm2 start ecosystem.config.js (Inicia servicios en segundo plano)
